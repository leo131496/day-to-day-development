代码和访问入口已由 GitHub 托管。完成云服务发布后，同事和客户可以通过这个入口进入工作台。

配置选择单个常驻服务和 5GB 持久磁盘，用于保存数据库、历史记录和备份。请在平台确认最新价格；不要改用没有持久磁盘的临时存储。当前入口不会把尚未发布的系统显示为可用。

前往 Render 授权并部署 ↗
  1. 01

    授权 GitHub 仓库

    使用你的账号登录 Render，授权读取 day-to-day-development 仓库。部署配置会从仓库中的 render.yaml 读取。

  2. 02

    设置管理员密码并检查存储

    为 BOARD_PASSWORD 设置至少 12 个字符的密码，保存在云平台的环境变量中。核对持久磁盘挂载位置是 /var/data，再确认服务费用和发布。密码不要写进 GitHub。

  3. 03

    核对数据和功能

    首次部署会初始化原始项目计划；这不等于已迁移本机数据库。本机已有的账号、填写内容和历史记录需要从完整备份迁移，核对后再交给同事和客户使用。

  4. 04

    连接公开访问地址

    部署成功后，将平台提供的 HTTPS 网址发回当前对话。完成登录、保存、重启保留数据的检查后，再将网址连接至 GitHub 访问入口。后续更新代码可由云平台自动发布。

GitHub Pages 提供访问入口；账号与业务数据由云端服务管理。不同账号目前拥有独立项目空间。请妥善保管管理员密码，并将数据库备份另存到独立位置。
