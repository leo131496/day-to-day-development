前往 Render 免费部署 ↗
  1. 01

    先创建免费云数据库

    在 Turso ↗ 注册并选择 Free，创建数据库，取得数据库 URL 和读写 Token。需要沿用本机记录时，先将完整备份迁移到空数据库。

  2. 02

    授权 GitHub，选择 Free

    使用你的账号登录 Render，授权读取当前仓库。配置已选择免费实例，不添加付费磁盘；将 TURSO_DATABASE_URL、TURSO_AUTH_TOKEN 填入云平台环境变量，设置至少 12 个字符的 BOARD_PASSWORD，再发布。

  3. 03

    核对数据和保存功能

    检查云端项目、账号和历史是否与迁移结果一致。验证保存、导入、重启后保留记录。管理员可在账号设置下载完整数据库备份，另存到私人存储。

    连接公开访问地址

    部署成功后，将平台提供的 HTTPS 网址发回当前对话。完成检查后，再连接到 GitHub 访问入口，供同事和客户访问。
